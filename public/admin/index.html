How do I get a token?
  1. Open GitHub → New fine-grained token.
  2. Name it “Portfolio admin” and pick an expiry (a year is fine).
  3. Repository access: Only select repositories → matthewfregnan-website.
  4. Permissions → Repository → Contents: Read and write.
  5. Generate, copy, and paste it above. This browser remembers it.

Only someone with write access to the repo can create a token that saves, so this page is safe even though anyone can open it.
